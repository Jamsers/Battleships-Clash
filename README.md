# Battleships-Clash
A simple infinite runner game, set on water. Available for Windows, on itch.io.  
Originally published as an Android game.

## Development Environment

Built in Unity 5.6.7. Windows installer built with NSIS.

[![Unity 5.6.7](https://img.shields.io/badge/Unity-5.6.7-black.svg?style=for-the-badge&logo=unity&logoColor=white)](https://unity.com/releases/editor/whats-new/5.6.7) [![NSIS](https://img.shields.io/badge/NSIS-blue.svg?style=for-the-badge&logo=nsis&logoColor=white)](https://nsis.sourceforge.io/Main_Page)

## How to Build
Battleships-Clash is built in Windows.

1. Install Unity 5.6.7. No other modules required.
1. Clone or download this repository. Open the repository folder with Unity 5.6.7.
1. Go to File and select Build & Run.

To build the Windows installer:

1. Install NSIS.
1. Open the repository folder, go to `.\NSIS script\`, and compile `Battleships_Clash_Installer.nsi` with the NSIS compiler. (`makensisw.exe`)
